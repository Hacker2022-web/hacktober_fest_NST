how it works

Around it, the rest of the harness: real-time taint tracking from untrusted sources to sensitive sinks, sub-millisecond checkpoint state rewinds, and an immutable forensic audit trail of every compromised thought.

questions

Key architectural clarifications on in-flight behavioral firewalling.

How is this different from NeMo Guardrails or LlamaGuard?

Pre-flight guardrails only inspect the initial user prompt. They are blind to data ingested during multi-step tool calls (e.g., invoices, scraped web pages, emails). Whipper inspects candidate tool calls in-flight before side-effects execute.

Does state rollback restart the entire workflow?

No. Whipper checkpoints immutable agent memory at each step. On violation, it rewinds only to the last clean pre-execution frame (<1ms), applies a security mask to neutralize the injection, and allows the agent to self-heal and finish its mission.
